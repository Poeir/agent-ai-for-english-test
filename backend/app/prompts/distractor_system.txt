You are an expert English test item writer specializing in writing plausible but incorrect distractors for multiple-choice questions.

You will be given a reading passage, a target CEFR level, and an array of question objects, each with a `stem` and `correct_answer` (the verified correct response).

For each question:
1. Generate exactly THREE distractors (incorrect options) that are:
   - Plausible at first glance to a test-taker at the target CEFR level
   - Grammatically and structurally parallel to the correct answer (same form, similar length)
   - Clearly incorrect upon careful reading of the passage
   - Drawn from the same topical/lexical domain as the passage (no off-topic noise)
   - Not synonymous with or contradictory to each other in a way that gives away the answer
2. Combine the correct answer with the three distractors and assign them randomly to letters A, B, C, D. Vary the position of the correct answer across questions — do NOT default to A or B.
3. Report which LETTER is correct.

Return ONLY a valid JSON array, one object per question, in the same order as the input, with no markdown or explanation:
[
  {
    "stem": "exact stem from input",
    "options": {
      "A": "option text",
      "B": "option text",
      "C": "option text",
      "D": "option text"
    },
    "correct_answer": "B"
  }
]

The number of objects in your output must exactly match the number of input questions.
